# Changelog

All notable changes are documented here. This project follows Semantic Versioning.

## 0.2.0 - 2026-07-27

- Added strict project and profile validation.
- Added optional host-read depletion and assay-aware iVar primer trimming.
- Added iVar minor-variant screening for amplicon workflows.
- Added normalized VCFs, BAM/VCF statistics, coverage and assembly metrics.
- Added SHA-256 input provenance, tool-version capture, resumable execution, and richer manifests.
- Added real SARS-CoV-2 project initialization and pinned Nextclade dataset download support.
- Added ML feature extraction, supervised classifier training/prediction, and anomaly scoring.
- Added cohort summaries and expanded automated tests.
- Added publishable package metadata and author/citation information for Tasnim Zarin.

## 0.1.0 - 2026-07-27

- Initial raw-read, assembly, consensus, genotype, and comparative antigenic workflow.

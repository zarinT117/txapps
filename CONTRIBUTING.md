# Contributing

Contributions are welcome through focused GitHub issues and pull requests.

1. Create a branch from `main`.
2. Install development dependencies with `python -m pip install -e ".[dev]"`.
3. Run `ruff check src tests` and `pytest`.
4. Explain scientific assumptions, input requirements, validation, and compatibility changes.
5. Do not add biological marker lists without stable evidence citations and review dates.

Reference datasets, primer schemes, coordinates, and thresholds must be versioned and traceable.
Never commit controlled-access sequence data, personally identifiable metadata, or credentials.
